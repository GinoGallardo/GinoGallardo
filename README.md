# 🚀 Proyectos

## 🚦 SIGET
### Sistema Inteligente de Gestión y Evaluación de Tránsito

Plataforma para gestionar, editar y simular redes semafóricas utilizando datos reales y simulación de tránsito.

Permite trabajar con:

- Redes semafóricas
- Cruces e intersecciones
- Fases y planes semafóricos
- Ciclos y offsets
- Conexiones y movimientos
- Visualización geográfica
- Simulación de tránsito
- Estados semafóricos en tiempo real
- Integración con SUMO y TraCI

**Tecnologías**

`React` `TypeScript` `Vite` `Tailwind CSS` `Python` `FastAPI` `SUMO` `TraCI` `WebSocket` `Leaflet` `OSM`

---

## 🚘 SITRAV
### Sistema Inteligente de Tránsito Vehicular

Sistema de análisis de tránsito mediante **Inteligencia Artificial y visión por computadora**.

Procesa cámaras de tránsito para detectar, seguir y contabilizar vehículos en tiempo real.

Entre sus funcionalidades se encuentran:

- Detección de vehículos
- Tracking de objetos
- Conteo por carriles
- Zonas de interés
- Eventos y alertas
- Cámaras RTSP
- Streaming de video
- Procesamiento mediante GPU
- Dashboards en tiempo real
- Integración con cámaras de distintas marcas

**Tecnologías**

`Python` `FastAPI` `YOLO` `ByteTrack` `OpenCV` `PyTorch` `CUDA` `FFmpeg` `RTSP` `WebSocket` `React`

---

## 🎥 SUV
### Sistema Unificado de Videovigilancia

Plataforma VMS para administración y monitoreo centralizado de cámaras.

El proyecto incorpora:

- Visualización de cámaras en vivo
- Grillas multi-cámara
- Control PTZ
- Gestión de dispositivos
- Reinicio remoto de cámaras
- Información y estado de cámaras
- Integración ONVIF
- Streaming RTSP / WebRTC
- Integración con Milestone XProtect
- Reproducción y almacenamiento de video

**Tecnologías**

`React` `Python` `FastAPI` `ONVIF` `RTSP` `WebRTC` `FFmpeg` `Milestone API`

---

## 🌐 NetMap
### Plataforma de gestión y visualización de infraestructura de red

Sistema que centraliza información proveniente de distintas herramientas de infraestructura.

Integra:

- NetBox
- MikroTik / WinBox
- Zabbix
- Archivos KML
- Fibra óptica
- Nodos de comunicaciones
- Dispositivos de red
- Servidores
- Enlaces y conexiones

El objetivo es disponer de una **vista unificada y georreferenciada de toda la infraestructura tecnológica**.

---

## 🔵 FoRed
### Fibra Óptica Red

Aplicación web y móvil para realizar relevamientos de infraestructura de fibra óptica instalada en calle.

Permite registrar y documentar:

- Trazas de fibra óptica
- Botellas de empalme
- Cámaras de inspección
- Recorridos
- Elementos de infraestructura
- Información técnica
- Relevamientos de campo
- Informes completos de cada fibra

Su objetivo es digitalizar y centralizar la documentación de la infraestructura de fibra óptica.

---

## 🚗 CAV
### Control de Acceso Vehicular

Sistema para control inteligente de acceso vehicular en edificios, consorcios y otras instalaciones.

Incluye:

- Reconocimiento automático de patentes
- Registro de vehículos autorizados
- Gestión de residentes
- Gestión de visitas
- Apertura automática de portones
- Registro y auditoría de accesos
- Operación local incluso sin conexión a Internet

**Tecnologías**

`React` `FastAPI` `Python` `PostgreSQL` `WebSocket` `Computer Vision` `Docker`
